أولًا: اختر الإجابة الصحيحة من بين الأقواس (15 سؤال)

س1: لكتابة تعليق في كود VB.NET نستخدم:

الإجابة الصحيحة: Rem

س2: تبدأ تسمية المتغير في VB.NET بـ:

الإجابة الصحيحة: حرف أو شرطة سفلية

س3: النوع المناسب لتخزين العمر هو:

الإجابة الصحيحة: Byte

س4: تبدأ الثوابت بالأمر:

الإجابة الصحيحة: Const

س5: MsgBox تستخدم لـ:

الإجابة الصحيحة: طباعة رسالة للمستخدم

س6: الأمر المستخدم للإعلان عن متغير هو:

الإجابة الصحيحة: Dim

س7: صيغة التخصيص الصحيحة هي:

الإجابة الصحيحة: X = 5

س8: ناتج تنفيذ: 2 + 3 * 4 هو:

الإجابة الصحيحة: 14

س9: نوع البيانات Boolean يُستخدم لـ:

الإجابة الصحيحة: قيم منطقية

س10: عند تنفيذ 3 (mod) 19 الناتج هو:

الإجابة الصحيحة: 1

س11: لكتابة التاريخ في VB.NET نستخدم علامتي:

الإجابة الصحيحة: #

س12: الخطأ الناتج عن كتابة الكود Din x As Long بشكل غير صحيح يسمى:

الإجابة الصحيحة: خطأ لغوي (Syntax Error)

س13: لإنشاء سطر جديد نستخدم الأمر:

الإجابة الصحيحة: VBCRLF

س14: ما نوع البيانات المناسب لتخزين قيمة مثل 3.14؟

الإجابة الصحيحة: Double

س15: ناتج تنفيذ أي تعبير شرطي يكون هو:

الإجابة الصحيحة: True أو False

الإجابة الصحيحة: ✓ صح

الإجابة الصحيحة: ✗ خطأ

س18: النوع String يُستخدم لتخزين الأرقام فقط.

الإجابة الصحيحة: ✗ خطأ

الإجابة الصحيحة: ✓ صح
